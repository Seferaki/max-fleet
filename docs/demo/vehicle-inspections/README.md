# Синтетические фотографии осмотра

Набор создан для демонстрации пользовательского сценария из [PRODUCT_SPEC.md, раздел 9](../../../PRODUCT_SPEC.md#9-фотографии-единый-стандарт-до-и-после): ровно 8 обязательных ракурсов до поездки и 8 после неё для каждой машины.

## Сценарии

| Машина из синтетического seed | До поездки | После поездки | Сценарий |
|---|---|---|---|
| `DEMO-001` — учебный седан 1, тёмно-синий | 12 000 км, 100% топлива | 12 048 км, 75% топлива | Обычная поездка, новых замечаний нет |
| `DEMO-003` — учебный хэтчбек 1, красный | 13 000 км, 50% топлива | 13 042 км, 25% топлива | После поездки отмечена неглубокая царапина справа сзади; крупный план вложен как дополнительное фото замечания |

У каждого осмотра есть по одному кадру: спереди, сзади, левый и правый борт, передняя и задняя части салона, багажник и приборная панель. Имена файлов совпадают с номерами ракурсов, которые запрашивает бот.

## Файлы

- `DEMO-001/before/` и `DEMO-001/after/` — по 8 ракурсов без нового повреждения.
- `DEMO-003/before/` и `DEMO-003/after/` — по 8 ракурсов; небольшая царапина видна в after-наборе с правого/заднего ракурса.
- `DEMO-003/issue/issue-closeup.jpg` — дополнительное фото замечания, не входит в обязательные 8.
- [`manifest.json`](manifest.json) — машина, этап осмотра, показания и пути к каждому ракурсу.

Файлы сохранены как JPEG с длинной стороной до 1280 px. Общий набор включает 33 изображения.

## Важно

Все кадры сгенерированы ИИ и являются синтетическими демонстрационными материалами. Это не реальные автомобили, осмотры или доказательства повреждений. Показания приборной панели предназначены для демо; значения сценариев выше — ожидаемые тестовые значения из синтетического seed. Не использовать набор как реальные данные автопарка.
