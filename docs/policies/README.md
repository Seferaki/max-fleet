# Политики MAX Fleet

Версия 1, 30.09.2026. Набор подготовлен для MVP по запросу владельца проекта.

## Статус

- Для demo/test с синтетическими данными этот набор описывает обязательное поведение продукта.
- Разделы о сроках хранения, доступе и реагировании на инциденты — проект внутренних правил будущего оператора, а не утверждённая юридическая политика компании.
- До загрузки реальных данных оператор должен указать свои реквизиты и ответственных, утвердить правовые основания, сроки, круг доступа и процедуру резервирования. Автоматическое удаление по предложенным срокам ещё не реализовано.
- Этот набор не является пользовательским уведомлением или юридическим заключением.

## Документы

- [Правила эксплуатации автомобилей](VEHICLE_USE.md) — выдача, фото 8+8, удержание на 15 минут, возврат и административное закрытие.
- [Данные, доступ и сроки хранения](DATA_PROTECTION.md) — категории данных, роли доступа и предлагаемые сроки.
- [Резервирование и восстановление](BACKUP_RECOVERY.md) — копии PostgreSQL/S3, проверка восстановления и запрет разрушительного отката.
- [Реагирование на инциденты](INCIDENT_RESPONSE.md) — первые действия при утечке, потере доступа, сбое и повреждении данных.
- [Синтетический набор](../demo/SYNTHETIC_DATASET.md) — состав уже подготовленных тестовых записей и ограничение их использования.
