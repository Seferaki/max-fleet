# Экран ручного выбора парковки (UI-01)

React/TypeScript + MAX UI/Bridge + Leaflet. Экран получает raw `window.WebApp.initData` только из Bridge и отправляет его в заголовке `Authorization: MaxInitData …` при каждом запросе к Go. В URL находится только `return_id` текущего черновика. `initDataUnsafe` не используется.

ID возврата берётся из `return_id` в URL либо `start_param` MAX deep link. Это только подсказка маршрута: Go отдельно проверяет подпись initData и владение именно текущим возвратом. Карта показывает последнюю парковку или центр города без выбранной точки. Пользователь нажимает на карту, перетаскивает маркер или вводит координаты вручную, затем явно сохраняет точку. Разрешение GPS не требуется. При ошибке тайлов ввод координат остаётся доступным. При сетевой ошибке маркер и `Idempotency-Key` сохраняются для повторной отправки; при новом открытии сохранённая точка читается из Go.

Публичные параметры сборки: `VITE_MAP_TILE_URL` и `VITE_MAP_ATTRIBUTION`. По умолчанию используются тайлы OpenStreetMap. Сборку нужно отдавать по HTTPS вместе с reverse proxy `/api/v1/` на gateway; локальный `vite` работает с тем же API через proxy после настройки сервера. Настоящий MAX Bridge и доменный Python-сервис проверяются отдельно на INT.

Проверки из `web/`: `npm ci`, `npm run typecheck`, `npm test`, `npm run build`. Тесты используют синтетические данные и mock HTTP, без реального MAX.
