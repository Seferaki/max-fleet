# Go gateway и Data API mock

`cmd/gateway` пока обслуживает только `/health/live` (200) и `/health/ready` (503). Go DataAPI client и отдельный `cmd/data-mock` поддерживают часть v1 контракта: чтение машин, своего состояния, правил, hold на 15 минут, math take/return, принятие правил, 8+8 фото, start/return и замечания без staged-фото. Mock проверяет actor, версии, идемпотентность и сохраняет snapshot/assets на диске. Остальные маршруты, outbox и контрактные сценарии ещё не завершены. `/health/ready` mock остаётся 503; это намеренное обозначение неполной реализации. `APP_ENV=production` запрещает запуск mock. MAX и Python-сервис ещё не подключены.

Версия Go фиксируется в `go.mod`; официальный SDK MAX закреплён на `v2.4.1`. Проверки из этого каталога: `go test ./...`, `go vet ./...`, `go build ./cmd/gateway ./cmd/data-mock`. Для отдельного запуска mock задайте ровно один из `DATA_API_TOKEN` (только локальный dev) или `DATA_API_TOKEN_FILE` (приватный файл), а также `DATA_MOCK_SNAPSHOT_FILE` на постоянном томе. Повреждённый snapshot блокирует старт вместо сброса к seed.

Compose для локальной разработки на Windows: из корня репозитория выполните `$env:MAX_FLEET_DATA_API_TOKEN_FILE = & powershell -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-compose-token.ps1`, затем `docker compose -f deploy/compose.backend.yaml up --build -d`. Скрипт создаёт токен через bootstrap, если его нет, и копирует его без вывода значения в игнорируемую `.local/compose-secrets/` с доступом только пользователя и Windows SYSTEM: Docker Desktop не смог смонтировать пользовательский файл из LocalAppData напрямую. На другой ОС задайте `MAX_FLEET_DATA_API_TOKEN_FILE` путём к приватному файлу самостоятельно. Для остановки без удаления snapshot: `docker compose -f deploy/compose.backend.yaml down`. Compose запускает один mock и gateway, публикует только gateway на `127.0.0.1:8080`, хранит snapshot/assets в `data_mock_state` и передаёт токен через Docker secret. Healthcheck проверяет `/health/live`; `/health/ready` остаётся 503 до завершения mock и не является доказательством готовности MAX.
